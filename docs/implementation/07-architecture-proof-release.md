# Phase 6: Architecture-Proof Release

Publish `v0.1.0-preview.1` only after generated daemon/TUI applications execute
OpenAI streaming, compiled coding tools, and a runtime-plugin tool with complete
cancellation and deterministic events. The TUI must reconnect through bounded
replay and selected interface implementations must be visible in inspectable
generated Go.

Release archives are reproducible and signed with checksums, SBOMs, provenance,
and independent verification. This is an SDK architecture proof, not a promise
of daily-use coding-product support. **Status:** planned.
