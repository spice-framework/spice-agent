# Phase 8 clean-room public-authoring contract

The project has two maintainers and cannot truthfully require an outside human
author. External authorship was therefore an unachievable social dependency,
not a product, security, or compatibility property. It is removed as a release
blocker and is never simulated or claimed.

The replacement preserves the useful test: can a consumer build an extension
without maintainer-only knowledge? The canonical contract is
`compatibility/public-authoring.json`, referenced by
`compatibility/policy.json` and enforced by the root quality gate.

Completion requires three separately versioned modules. Each proof must:

- begin in a repository-external clean directory with fresh module and build
  caches and `GOWORK=off`;
- consume only immutable released modules, tools, and public documentation;
- contain no `replace`, `exclude`, or `retract` directive, private/internal
  import, absolute workspace path, or dependency on a maintainer checkout;
- include a generated Spice composition proof and committed reproducible
  vendor tree;
- complete install, configure, debug, test, package, and deletion exercises;
- pass on `linux/amd64` and `windows/amd64`, including vendor-offline tests; and
- record exact module, version, commit, profile, platforms, and hosted
  verification evidence before the manifest may set `proven`.

Models may review the public instructions and resulting source, but model
review is not represented as human authorship. Existing first-party experiments
do not satisfy this contract because they were developed with repository
context and before the public clean-room boundary was frozen.

## First proof: deterministic text tool

The first separately versioned proof is
`github.com/spice-framework/spice-agent-tool-text@v0.1.0-preview.1`. Annotated
tag object `36539996097937196711433a1e501d299b8fbe9f` resolves to commit
`cbc738067e9f67efd273509481488ba5eadfe1bd`. The public Go proxy and SumDB
resolve that exact source with module sum
`h1:e9qhtkySbuL/47k/dx9S9U0Y17MhI42p0pcEBrruPF4=` and go.mod sum
`h1:OEMtMFjM4RDQ7dbPqjTdIEGuvJIQsWPvq2bug66tT6M=`. The non-draft GitHub
prerelease is the canonical human-readable release record.

The module contributes one deterministic read-only `text.inspect` tool through
explicit blank-import auto-configuration. It was scaffolded with the immutable
`compiled-tool-autoconfigure/v1alpha1-preview6` profile, generated by Toolchain
preview2 with ownership schema 6, and contains no workspace replacement or
private import. Hosted run
[`31442525658`](https://github.com/spice-framework/spice-agent-tool-text/actions/runs/31442525658)
passed from fresh caches on Ubuntu and Windows: committed-vendor offline
verification plus install, configure, debug, test, package, and deletion
operations. A separate repository-external consumer then fetched only the
public proxy tag, generated an eight-file application, disabled the proxy, and
passed the same operational boundary; deletion removed the activation import
and regenerated without `text.inspect` ownership.

This one record satisfies the public-authoring portion of the SDK beta
criterion. Phase 8 remains incomplete until two additional separately
versioned evidence records exist. The public-authoring and generated-source v1
blockers therefore remain active.
