# Phase 3: Provider and Coding Tools

**Objective:** prove the public seams with OpenAI Responses and read,
atomic-replace/write, and shell tools in separate repositories. Provider retries
only failures known to precede streaming. Credentials are typed, redacted, and
never serialized into events or generated source.

Coding tools have bare user-process privileges, declare capabilities, bound
input/output, cancel process trees, and display an explicit warning. **Exit:**
offline scripted flow plus opt-in live acceptance. **Status:** planned.
