# Phase 8: Stress Prototypes and Stabilization

Before stabilizing APIs, isolate four prototypes: a permission decorator proving
canonical dispatch interception; SQLite event/snapshot recovery; an alternate UI
shell; and a two-worker extension with no kernel parent/child model.

After those pass, validate three independently authored compiled extensions, Go
and Python plugins, and a second client. Optional MCP, Git, indexing, telemetry,
planning, sandbox, and subagent integrations remain outside the kernel. Release
v1 only after public compatibility policy freezes. **Status:** planned.
