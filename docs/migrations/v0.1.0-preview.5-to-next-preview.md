# Agent preview5 to the next preview

Current `main` contains a reviewed pre-release source migration which is not a
published release contract.

- `plugin/host.HostConfig.Processes` now accepts `process.VerifiedLauncher`.
- `plugin/host/autoconfigure.DefaultHost` receives the same verified launcher.

Use `process.NewVerifiedLauncher` with the exact executable identity and
containment policy. This prevents a path-only launcher from bypassing the
digest and process-containment boundary. The change is intentionally recorded
before a new preview is authorized; it must not be described as a released
generation until that release exists.
