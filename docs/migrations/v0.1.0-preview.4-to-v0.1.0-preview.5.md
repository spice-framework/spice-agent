# Agent preview4 to preview5

Preview5 is a reviewed pre-1.0 hard cut. It does not promise source
compatibility with preview4.

- Pass the run-owned `stage.ToolDispatchScope` to
  `stage.ToolDispatcher.Dispatch`. Guards must preserve the scope unchanged.
- Pass the canonical workspace fingerprint to `agent.NewPlanIdentity`.
- Inject the ordered `[]stage.ToolDispatchGuard` collection into
  `autoconfigure.DefaultHost` and `agent.EngineOptions`.
- Rebuild generated composition with the pinned Spice toolchain. Do not edit
  generated files.

Snapshots from v1alpha1 or v1alpha2 and plan identities from v2 are rejected.
Create a new run under snapshot v1alpha3 and plan identity v3; there is no
automatic migration because workspace and dispatch authority cannot be
reconstructed safely.
