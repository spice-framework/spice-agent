# Agent preview5 to preview6

Preview6 changes the runtime-plugin host launcher contract:

- `plugin/host.HostConfig.Processes` now accepts `process.VerifiedLauncher`.
- `plugin/host/autoconfigure.DefaultHost` receives the same verified launcher.

Use `process.NewVerifiedLauncher` with the exact executable identity and
containment policy. This prevents a path-only launcher from bypassing the
digest and process-containment boundary. The source-breaking transition is
published by `v0.1.0-preview.6`; callers upgrading from preview5 must migrate
their host launcher before recompiling.
